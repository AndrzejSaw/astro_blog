# Как подружить Astro и Tailwind CSS

Дата публикации: 1 декабря 2024 года

Astro предлагает быстрый старт, а Tailwind CSS — удобный способ собирать интерфейсы из утилитарных классов.
В статье показываю, как за 15 минут подключить Tailwind к проекту и настроить дизайн-токены под задачи команды.

## Шаг 1. Устанавливаем плагины

```bash
npm install -D tailwindcss @tailwindcss/vite
```

Подключаем плагин в `astro.config.mjs`:

```js
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  vite: {
    plugins: [tailwindcss()],
  },
});
```

## Шаг 2. Создаём глобальные стили

В `src/styles/tailwind.css` импортируем фреймворк и добавляем кастомные слои, если это нужно проекту.
Полезно описать базовые стили в `@layer base`, чтобы унифицировать типографику.

## Шаг 3. Настраиваем дизайн-токены

Создайте `tailwind.config.ts` и вынесите в него цветовую палитру, размеры шрифтов и z-index.
Это позволит использовать единую систему на всех страницах.

## Полезные советы

- Храните часто используемые компоненты в `src/components` и выделяйте имена классов в переменные.
- Используйте директиву `@apply` осторожно — только для готовых паттернов.
- Проверяйте итоговый CSS, чтобы не тянуть в продакшен лишние стили.
